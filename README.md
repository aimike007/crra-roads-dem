# CRRA Roads Map: demo

Demo of the Coosawattee River Resort Association Roads Map with a live "follow me" location dot,
for showing the Roads & Grounds team. Snapshot of Nov 15, 2026. The working version lives on the
CRRA Roads & Grounds SharePoint site; a CRRA sign-in version is planned.

No owner names. Surface, culverts and steepness are drafts from 2018–19 public USGS lidar.
